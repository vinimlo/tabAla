## Detailed Description

```
TabAla is a minimalist extension for temporary link organization.

Perfect for anyone who accumulates tabs and needs a temporary place to organize them before processing.

✨ FEATURES

• Save the current tab with one click
• Organize links into custom collections
• Kanban dashboard with drag-and-drop
• Automatic Inbox for uncategorized links
• Replaces the new tab page (optional)

🎯 WHO IS IT FOR

• Researchers collecting references
• Professionals managing multiple projects
• Students organizing study material
• Anyone who hoards tabs "for later"

🔒 PRIVACY

• Your data stays 100% local
• No information sent to servers
• No tracking or analytics
• Open source on GitHub

📦 LIGHTWEIGHT & FAST

• Under 300KB in size
• Instant interface
• Zero external network dependencies
• Works 100% offline

💡 HOW TO USE

1. Click the extension icon
2. Choose a collection (or use the Inbox)
3. Click "Save"
4. Open the Dashboard to organize with drag-and-drop

🆓 FREE & OPEN SOURCE

TabAla is free, ad-free, and open source. Contributions are welcome on GitHub!
```

## Review Notes for Google

```
TabAla is a simple productivity extension that helps users organize links temporarily.

Key points:
- Does not collect user data
- Does not require an account or login
- Works offline
- Open source and available for audit
- Only requests the minimum permissions needed for functionality

The extension replaces the new tab page to display the dashboard — this is a core feature, not unintended behavior.
```

---

## Single Purpose

```
TabAla has a single purpose: temporary link organization.

It provides a minimalist "waiting room" where users can save browser tabs
and organize them into collections for later processing. Every feature in
the extension — saving tabs, creating collections, the Kanban dashboard,
workspaces, and search — directly supports this single workflow:
save → organize → process.

The extension does not include unrelated functionality. It does not manage
bookmarks, block ads, modify web pages, or perform any task outside of
temporary link organization. All permissions (storage, tabs, tabGroups,
activeTab) are strictly required to save, organize, and retrieve the
user's links. No data leaves the browser.
```
